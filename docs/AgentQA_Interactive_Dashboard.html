Complete API Endpoint & Protocol Reference Matrix

Endpoint / Command Protocol Trigger File Payload & Action
POST /webhook/gitlab Inbound Webhook WebhookController.java Validates token, filters event, deduplicates, saves Run status=QUEUED.
GET /projects/{p}/merge_requests/{i} GitLab REST v4 GitLabClient.java Fetches MR title and description.
GET /projects/{p}/merge_requests/{i}/changes GitLab REST v4 GitLabClient.java Fetches changed files list and git diffs.
GET /projects/{p}/repository/files/{f}/raw GitLab REST v4 GitLabClient.java Downloads raw Java source file from branch.
POST /openai/v1/chat/completions Groq LLM API LlmClient.java Executes prompts for Analyst, Writer, Triage, Fixer using openai/gpt-oss-120b.
docker run --rm -v work:/app maven:... Docker Subprocess RunnerAgent.java Runs mvn test inside sandbox container with 5-minute timeout.
POST /projects/{p}/repository/branches GitLab REST v4 GitLabClient.java Creates fix branch agentqa/fix-mr-{iid}.
PUT /projects/{p}/repository/files/{f} GitLab REST v4 GitLabClient.java Commits corrected source file to fix branch.
POST /projects/{p}/merge_requests GitLab REST v4 GitLabClient.java Opens the New Auto-Fix Merge Request!
POST /projects/{p}/merge_requests/{i}/notes GitLab REST v4 GitLabClient.java Posts Markdown summary note on the original MR.
GET /dashboard/stream Server-Sent Events DashboardController.java Streams real-time JSON timeline updates to UI.
