6. GraphRunner.java

com.agentqa.graph.GraphRunner

Purpose: The hand-rolled state machine engine. Discovers all Spring agent beans and indexes them into a Map<Agent.Node, Agent>.

// State Machine Transition Matrix (next method) 
ANALYST -> TEST_WRITER
TEST_WRITER -> RUNNER
RUNNER -> (buildPassed ? REPORTER : TRIAGE)
TRIAGE -> ("TEST_ERROR".equals(verdict) ? (attempts < 3 ? TEST_WRITER : REPORTER) : FIXER)
FIXER -> REPORTER
REPORTER -> END

7. AnalystAgent.java

com.agentqa.agent.AnalystAgent
Responsibilities & Logic:
  • Fetches MR info via GitLab API (getMergeRequest, getChanges, getFile).
  • Extracts package declaration via helper: packageOf(source).
  • Prompts Groq LLM: "Judge the code against what the merge request promises, not against itself."
  • Stores JSON Test Plan in state.setTestPlan().

8. TestWriterAgent.java

com.agentqa.agent.TestWriterAgent
Responsibilities & Prompt Rules:
  • Increments writerAttempts.
  • Forces test class to declare the SAME package as the class under test.
  • Enforces defensive rules: no reflection, no assumptions, no assertion weakening.
  • Appends lastBuildError on retry passes.

9. RunnerAgent.java

com.agentqa.agent.RunnerAgent
Responsibilities & Docker Mechanics:
  • Creates package-matching directory structure: src/main/java/com/demo/shop/CartService.java.
  • Executes ProcessBuilder: docker run --rm -v work:/app maven:3.9-eclipse-temurin-21 mvn -q -B test.
  • Enforces 5-minute timeout protection (process.waitFor(5, TimeUnit.MINUTES)).

10. TriageAgent.java

com.agentqa.agent.TriageAgent
Responsibilities & Classification:
  • Evaluates build failure context. Prompts Groq LLM.
  • Classifies verdict: TEST_ERROR (retry writer) or CODE_DEFECT (route to FIXER).

11. FixerAgent.java

com.agentqa.agent.FixerAgent
Responsibilities & Auto-Fix MR Pipeline:
  • Generates corrected source code using Groq LLM.
  • Re-verifies fix locally in Docker via runner.build(state, fixed) (aborts if tests fail!).
  • Calls GitLab API: creates branch agentqa/fix-mr-{iid}, commits fixed file, and opens **New Auto-Fix MR on GitLab**!

12. ReporterAgent.java

com.agentqa.agent.ReporterAgent
Responsibilities:
  • Composes Markdown report (Passed / Defect Found + Fix MR Link / Retries Exhausted).
  • Posts comment note on original MR via gitlab.postComment().

15. WebhookController.java

com.agentqa.webhook.WebhookController
Webhook Controller Logic:
  • Endpoint: POST /webhook/gitlab
  • Header check: X-Gitlab-Token
  • Deduplication check: existsByProjectIdAndMrIidAndHeadShaAndStatusIn(QUEUED, RUNNING)
  • Saves new Run(QUEUED) to PostgreSQL database.

16. RunWorker.java

com.agentqa.worker.RunWorker
Scheduled Worker Mechanics:
  • Annotation: @Scheduled(fixedDelay = 3000)
  • Polls RunRepository.findByStatusOrderByCreatedAtAsc(QUEUED).
  • Updates status to RUNNING and calls GraphRunner.run(state).
  • Finalizes status to DONE or FAILED.

17 & 18. Run.java, StepRecord.java & Repositories

com.agentqa.run.*
JPA Database Mapping:
  • Run.java (@Table name = "runs"): id, projectId, mrIid, sourceBranch, headSha, status, createdAt, updatedAt.
  • StepRecord.java (@Table name = "steps"): id, runId, agent, attempt, startedAt, finishedAt, outcome, detail.
  • RunRepository & StepRecordRepository: Spring Data JPA Repositories.

19. RunController.java

com.agentqa.run.RunController
REST API Endpoints:
  • GET /runs: Returns recent run summaries list.
  • GET /runs/{id}: Returns detailed run timeline path (e.g. ANALYST#1 -> TEST_WRITER#1 -> RUNNER#1 -> TRIAGE#1 -> FIXER#1 -> REPORTER#1) and duration seconds per step.

20, 21 & 22. DashboardController.java & dashboard.html

com.agentqa.dashboard.*
Real-Time Streaming UI:
  • DashboardController.java: Exposes SSE endpoint GET /dashboard/stream using SseEmitter.
  • dashboard.html: Real-time web UI showing live node execution timeline, risk metrics, build pass/fail statuses, and direct links to newly opened Auto-Fix MRs!
